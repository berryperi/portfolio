### [프로젝트 1] Note Generator — AI 기반 리듬게임 채보 자동 생성 시스템

**프로젝트 개요**
PyTorch + CUDA 기반 Conformer 딥러닝 모델로 채보를 자동 생성하는 웹 서비스.
Docker 컨테이너 기반 GPU 모델 서빙 환경을 직접 구성하여 운영.

**공고 요건 연관 경험**

| 요건 | 경험 내용 |
|------|-----------|
| Docker 실무 경험 (설치·운영·문제 해결) | PyTorch + CUDA 12.1 + Gradio 환경을 **Docker Compose로 패키징·배포**, NVIDIA Container Toolkit으로 GPU 패스스루 구성, 볼륨 마운트로 대용량 모델(.pth) 분리 관리 |
| 서비스 배포 및 운영 대응 | 포트 7828 외부 접근 웹 서비스 운영, 컨테이너 환경과 개발 환경 일치 보장으로 배포 안정성 확보 |
| 모니터링 & 로그 분석 | 배치 추론 처리 중 진행 상태 실시간 출력, 처리 오류 발생 시 개별 파일 단위로 예외 처리하여 전체 서비스 중단 방지 |
| Python 자동화 작업 | PyTorch DataLoader 배치 처리, 오디오 전처리 파이프라인(리샘플링·Mel-Spectrogram 변환·프레임 분할) Python으로 구현 |

```yaml
# Docker Compose GPU 패스스루 구성
deploy:
  resources:
    reservations:
      devices:
        - driver: nvidia
          count: 1
          capabilities: [gpu]
```

**기술 스택**: Docker, Docker Compose, NVIDIA Container Toolkit, Python, PyTorch (CUDA 12.1), Gradio

### [프로젝트 2] AUControl — 게임 윈도우 AI 자동화 제어 플랫폼

**프로젝트 개요**
C# 클라이언트 + Python OCR 서버의 클라이언트-서버 분리 아키텍처로 설계한 자동화 플랫폼.
Python 서버를 Linux 환경에서 운영하며 장애 대응 및 서비스 안정성 유지.

**공고 요건 연관 경험**

| 요건 | 경험 내용 |
|------|-----------|
| Python 실무 경험 | **PaddleOCR REST API 서버 직접 설계·구현** — Python Flask 기반 HTTP 서버(Port: 5123), GPU/CPU 자동 감지, 모델 서버 시작 시 1회 로드 후 메모리 상주 |
| 장애 발생 시 원인 파악 및 대응 | GPU/CPU 상태 자동 감지 로직, 서버 헬스체크(`/health`) 엔드포인트 구현, 클라이언트 측 연결 실패 시 재시도 처리 |
| 서비스 안정성 관련 업무 | 다중 캡처 방식(DXGI·BitBlt·PrintWindow) 자동 전환으로 환경 변화 대응, 입력 방식(SendInput·PostMessage·Interception) 자동 전환 |
| 인프라 기본 이해 | Linux 서버 환경에서 Python 서버 운영, 포트 관리, HTTP 통신 설계 경험 |

**기술 스택**: Python, Flask, PaddleOCR PP-OCRv5, Linux 서버 운영, REST API, C# (.NET 8.0)

### [프로젝트 3] AUGraphics — 3D 아바타 그래픽 검수 자동화 툴

**프로젝트 개요**
게임 아바타 아이템 3D 검수 전 과정을 자동화한 Windows 내부 도구.
외부 AI 서버(VLM, 업스케일)와 REST API로 연동하여 운영 중 장애 상황에 대응하는 로직 포함.

**공고 요건 연관 경험**

| 요건 | 경험 내용 |
|------|-----------|
| 장애 분석 및 처리 | VLM/업스케일 서버 연결 실패 시 **자동 재시도 로직** (30초 대기 → 재연결 반복, CancellationToken으로 즉시 중단) |
| 모니터링 & 로그 분석 | 처리 단계별 실시간 로그 출력 + 로그 파일 자동 저장 — 장애 발생 시 어느 단계에서 실패했는지 추적 가능한 구조 |
| 서비스 안정성 설계 | 게임 클라이언트 크래시 감지 → 자동 재시작 → 해당 아이템 스킵 후 다음 처리 계속, 서비스 중단 없는 비동기 처리(async/await) 설계 |
| Python 자동화 | 3ds Max MaxScript 경로 동적 치환 → 임시 파일 생성 → 배치 실행 → 결과 CSV 파싱까지 자동화 파이프라인 구현 |

**기술 스택**: C# (.NET 8.0), Python, REST API 연동, 비동기 처리(async/await), 로그 관리

### [프로젝트 4] TTS/STT — 오픈소스 음성 AI 모델 로컬 서빙

**프로젝트 개요**
Hugging Face Hub에서 최신 음성 AI 모델을 다운로드하여 로컬 GPU 서버에 직접 서빙.
모델별 성능 비교 테스트 후 운영 모델 선정.

**공고 요건 연관 경험**

| 요건 | 경험 내용 |
|------|-----------|
| Python 실무 경험 | Transformers 라이브러리 기반 TTS/STT 추론 파이프라인 구현, REST API 형태로 서빙 |
| 서버 운영 경험 | 로컬 GPU 서버에 모델 서빙 환경 구성·운영, CUDA 기반 GPU 가속 추론 |
| 서비스 배포 및 운영 | 오픈소스 모델(SparkTTS, OpenAudio S1, Whisper) 로컬 배포 및 실사용 환경 운영 |

**기술 스택**: Python, PyTorch, Hugging Face Transformers, SparkTTS, OpenAudio S1, Whisper, CUDA
